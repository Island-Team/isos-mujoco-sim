# Package node groups

[Docs](../README.md) · [中文](../../docs_cn/node/README_cn.md)

These are package-contributed hardware types, rather than IsOS built-ins. Paths follow the IsOS node documentation structure `node/<core>/<layer>/<group>.md`. A group filename is not a complete registered type ID; a group can contain several types. Each reference owns purpose, availability, ports, payloads, carriers, rates, settings, defaults, rejection, and Stop behavior.

[EOS node groups](eos/README.md); exact package pins and service bindings are defined in [package](../package.md).
